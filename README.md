# AutonomousQA

Autonomous web QA agent.

## Setup

Clone the repository:

    git clone https://github.com/pradhansuman/AutonomousQA.git

Enter the directory:

    cd AutonomousQA

Install dependencies:

    python3 -m pip install -r requirements.txt

Install Playwright browsers:

    python3 -m playwright install

## Run

    python3 qa_agent_v8_8_FINAL.py https://the-internet.herokuapp.com/ --headless
